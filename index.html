PERSONAL SOFTWARE PROCESS

PLANIFICAR · MEDIR · MEJORAR
01 / PSP

Personal Software Process

PSP es un proceso de trabajo individual que ayuda al desarrollador a comprender y mejorar su propio desempeño mediante datos y disciplina.

  • Planificar tareas y estimar tiempos.
  • Registrar el esfuerzo y los defectos.
  • Revisar el trabajo antes de entregarlo.
  • Analizar los resultados para mejorar.

02 / TSP

Team Software Process

TSP organiza el trabajo de un equipo de desarrollo para alcanzar metas comunes, definir roles y entregar software de calidad.

  • Establecer objetivos y responsabilidades.
  • Distribuir tareas entre los integrantes.
  • Controlar el avance del proyecto.
  • Evaluar resultados como equipo.
